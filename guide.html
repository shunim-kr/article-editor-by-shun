아티클 편집기 사용 안내

아임웹에 올릴 글을 여기서 쓰고, 만들어진 코드를 아임웹에 붙여넣습니다. 편집기에 보이는 모습이 아임웹에 그대로 나옵니다.

편집기 열기 →

글 하나 발행하기 — 이 순서만 기억하세요

  1. Chrome으로 열기받은 편집기 링크(또는 파일)를 Chrome으로 엽니다. 쓰는 글은 자동 저장됩니다.
  2. 쓰기왼쪽 문서 정보에 제목·키워드를 넣고, 가운데 흰 화면에 본문을 씁니다.
  3. 복사오른쪽 위 HTML 복사 → 창에서 복사.
  4. 아임웹에 붙여넣기아임웹 글쓰기 → 툴바 코드보기 </> → 안의 내용을 전부 지우고 붙여넣기 → 코드보기를 다시 끕니다.
  5. 원고 보관편집기 위 저장을 눌러 원고 파일(.json)을 내려받아 둡니다.

4블록 옮기기 · 고치기

블록에 마우스를 올리면 왼쪽에 ＋ ⠿ 가 나옵니다.

  • ⠿ 를 잡고 끌면 원하는 자리로 이동
  • ⠿ 를 누르면 메뉴: 전환(본문↔제목·목록·콜아웃 등), 배경색(콜아웃·토글), 위로·아래로·복제·삭제
  • 여러 블록: 글 바깥 빈 곳에서 끌어 고른 뒤 Backspace로 삭제, ⠿로 함께 이동
  • 콜아웃·토글·열 안에서도 /로 제목·목록·이미지·표를 넣을 수 있습니다. 콜아웃 이모지는 눌러서 바꿉니다

⌘Z 되돌리기 · ⇧⌘Z 다시 실행. 지운 블록도 되살아납니다.

5이미지 — 아임웹에 먼저 올립니다

편집기는 사진 파일을 직접 올리지 못합니다. 아임웹에 올린 사진의 주소를 가져와 씁니다.

  • 아임웹 글쓰기 화면에 쓸 사진을 모두 업로드합니다 (글은 안 써도 됩니다)
  • 코드보기를 켜고 안의 내용을 전체 복사합니다
  • 편집기 왼쪽 이미지 → 아임웹 이미지 불러오기에 붙여넣습니다
  • 모인 사진을 누르면 본문에 들어갑니다

본문의 사진을 누르면 설정창이 열립니다. 너비·모서리·캡션을 정하고, 대체 텍스트는 꼭 적어주세요 (검색·접근성).

사진이 아직 없으면 방식을 자리표시자로 두세요. 회색 상자로 자리만 잡아두고, 아임웹에서 나중에 바꿔 끼웁니다.

6표

Tab다음 칸 (마지막 칸이면 새 행)
Enter아래 칸 (마지막 행이면 새 행)
Shift+Enter칸 안에서 줄바꿈
  • 행 왼쪽 ⋮ · 열 위 ⋯: 추가·삭제·배경색, 열은 정렬까지
  • 칸 오른쪽 위 ▾: 그 칸만 색칠
  • 열 사이 경계를 끌면 너비 조절, 표 아래·오른쪽 ＋로 행·열 추가
  • 제목 행·제목 열 켜고 끄기는 ⠿ 메뉴

엑셀·구글 시트에서 복사해 붙이면 그대로 표가 됩니다. 휴대폰에서는 표를 옆으로 밀어서 봅니다.

7버튼 · 유튜브

편집기에서 누르면 링크로 넘어가지 않고 설정창이 열립니다.

  • 버튼: 문구, 링크, 모양(사각·라운드·캡슐), 크기, 정렬, 색, 꽉 채우기. 링크는 열어보기로 확인
  • 유튜브: 영상 주소를 붙여넣습니다 (일반·youtu.be·쇼츠 모두 됨). 편집기에선 재생되지 않고, 발행하면 재생됩니다

8원고 관리

저장원고 파일(.json)을 내려받습니다
불러오기저장한 원고를 열어 이어 씁니다
새로 쓰기지금 글을 지우고 처음부터
한 브라우저에는 원고가 하나만 열립니다. 새 글을 시작하기 전에 꼭 저장하세요. 여럿이 동시에 편집하는 도구가 아닙니다. 다른 사람에게 넘길 때는 .json 파일을 보내고, 받은 사람이 불러오기로 엽니다.

9아임웹에서 고친 글 다시 가져오기

아임웹에 붙인 뒤 거기서 손본 글도 다시 편집기로 가져와 이어 쓸 수 있습니다.

  • 아임웹 코드보기 내용을 전체 복사
  • 편집기 왼쪽 아임웹에서 가져오기 → 아임웹 HTML 불러오기에 붙여넣기
  • 현재 원고 대체 또는 뒤에 이어붙이기

잘못 불러와도 ⌘Z로 되돌릴 수 있습니다.

10왼쪽 패널의 나머지

  • 발행 전 점검: 제목 길이, 키워드 수, 제목 순서, 이미지 대체 텍스트, 분량을 확인해 줍니다
  • 웹으로 공유 → 웹페이지로 저장: 아임웹에 올리기 전 검토용으로 보낼 한 장짜리 웹페이지를 만듭니다
  • 디자인 설정: 글자 크기·여백·색. 팀이 같은 모양을 쓰도록 바꾸지 마세요. 바꿨다면 기본값으로 되돌리기

11이럴 땐

  • 위에 '자동 저장 꺼짐'이 떠요 — Chrome이 아닌 브라우저입니다. Chrome으로 다시 열거나, 저장을 자주 눌러주세요
  • 아임웹에서 모양이 달라요 — 코드보기 안을 전부 지우고 붙였는지, 붙인 뒤 코드보기를 껐는지 확인하세요
  • 사진 대신 회색 상자가 나와요 — 자리표시자입니다. 아임웹에서 사진으로 바꿔 끼우세요
