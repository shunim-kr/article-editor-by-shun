열 배치 방식
표는 아임웹에서 확실히 동작하지만 휴대폰에서도 가로를 유지합니다. flex는 좁은 화면에서 세로로 쌓이지만 아임웹이 지우는 것으로 확인됐습니다.
모바일 대응
아임웹 게시판 설정 → 게시물 본문 상단 코드에 한 번 넣어두는 코드입니다. 세 가지를 맡습니다.
① 토글 접고 펴기 — 아임웹이 발행할 때 토글 기능을 지우기 때문에 이 코드가 되살립니다
② 휴대폰 글자 크기 — 편집기 크기가 최대, 좁은 화면에서 폭에 맞춰 작아집니다

▶웹으로 공유
더블클릭하면 브라우저에서 열리는 한 장짜리 웹페이지(.html)를 만듭니다. 남에게 링크로 보내려면 그 파일을 올릴 곳이 필요한데, 창 안에서 안내해 드립니다.
상단 저장은 원고 데이터(.json)로, 편집기에 다시 불러올 때 씁니다.
▶아임웹에서 가져오기
아임웹에서 손본 글을 코드보기에서 복사해 붙여넣으면 블록으로 되돌립니다. 이어서 편집할 수 있어요.
▶이미지
아직 불러온 이미지가 없습니다. 아임웹에 이미지를 먼저 올리고 코드보기 내용을 붙여넣으면 여기 모입니다.
▶AI 대체 텍스트
이미지를 넣으면 Claude 가 사진과 앞뒤 본문을 함께 보고 대체 텍스트를 씁니다. 직접 쓴 대체 텍스트는 덮어쓰지 않습니다. 이미지 설정창의 ✨ AI로 작성 으로 언제든 다시 쓸 수 있습니다.
키는 이 브라우저에만 저장되고, 원고 파일(.json)이나 다른 사람에게는 가지 않습니다. 이미지 한 장에 약 2센트(30원 안팎)의 사용료가 듭니다.

방향키
문단 끝에서 ↓·→ 를 누르면 다음 블록으로, 맨 앞에서 ↑·← 를 누르면 이전 블록으로 넘어갑니다.

지난 단축 입력
##  H2 · ###  H3 · ####  H4 · >  인용 · -  불릿 · 1.  번호 · --- 구분선

목록 단계
목록에서 Tab 한 단계 안으로 · Shift+Tab 한 단계 밖으로. 단계마다 기호가 바뀝니다 (● → ○ → ▪ / 1 → a → i)

블록 전환
⠿ → 전환. 본문을 제목·인용·콜아웃·토글·목록으로 바꿉니다. 토글로 바꾸면 글이 제목 칸으로 들어가고, 목록을 본문으로 바꾸면 항목마다 문단이 하나씩 생깁니다.

아임웹 왕복
아임웹에서 손본 글을 다시 편집기로 가져오려면 사이드바의 아임웹 HTML 불러오기. 코드보기 내용을 붙여넣으면 블록으로 되돌아옵니다.

웹으로 공유
사이드바 웹페이지로 저장 → 제목·여백을 갖춘 한 장짜리 웹페이지가 나옵니다. 아임웹에 올리기 전 검토용으로 보내거나, 블로그에 안 맞는 글을 링크로 공유할 때 씁니다.

원고 관리
새로 쓰기 처음부터 · 저장 .json 내려받기 · 불러오기 이어쓰기
Chrome 으로 열어주세요. 자동 저장이 됩니다. 다른 브라우저에서는 상단에 자동 저장 꺼짐이 뜰 수 있고, 그때는 저장으로 직접 보관해야 합니다.

여백
문단 사이를 더 띄우고 싶을 때 /여백. 소·중·대 또는 직접 입력(px)으로 높이를 정합니다. 편집기에서는 줄무늬로 보이지만 발행하면 빈 공간만 남습니다.

버튼 · 영상
편집기에서 버튼을 누르면 링크로 이동하지 않고 설정창이 열립니다. 링크는 설정창의 열어보기로 확인하세요. 풀와이드 버튼도 눌러서 바로 수정할 수 있습니다.

되돌리기
⌘Z 되돌리기 · ⇧⌘Z 다시 실행. 상단 ↶ ↷ 버튼도 같습니다. 삭제한 블록도 되살아납니다. 타이핑은 덩어리로 묶여 기록됩니다.

복사
블록을 선택한 뒤 ⌘C 하면 순수 텍스트로 복사됩니다. 목록은 -·번호가 붙고 단계별로 들여쓰기됩니다. ⌘X 는 복사 후 삭제.

여러 블록 한꺼번에
본문 바깥 빈 곳에서 끌면 여러 블록이 선택됩니다. 글자를 끌다 다음 블록으로 넘어가도 됩니다. Shift+클릭으로 범위 선택, Backspace로 삭제, Esc로 해제. 선택한 채 ⠿를 끌면 함께 이동합니다.

서식
⌘E 코드 표시 (글을 꾸미는 용도로 씁니다)
글자를 선택하면 서식 바가 뜹니다. ⌘B 굵게 · ⌘I 기울임 · ⌘U 밑줄 · ⌘K 링크 · A 글자색·형광펜
정렬 — 서식 바 오른쪽 끝의 왼쪽·가운데·오른쪽 버튼, 또는 ⠿ 메뉴의 정렬. 본문·제목·인용 블록 단위로 적용됩니다. 여러 블록을 고른 채 ⠿ 로 바꾸면 한꺼번에 바뀝니다.

콜아웃 · 토글 배경색
⠿ → 배경색 으로 12가지 중에서 고릅니다. 없음 을 고르면 배경 없이 글만 남습니다.

표
/표 로 넣습니다. Tab 다음 칸 · Shift+Tab 이전 칸 · Enter 아래 칸 · Shift+Enter 칸 안 줄바꿈. 마지막 칸에서 Tab 이나 마지막 행에서 Enter 를 누르면 행이 늘어납니다.
행 왼쪽 ⋮ · 열 위 ⋯ 손잡이로 추가·삭제·배경색·정렬, 칸 오른쪽 위 ▾ 로 그 칸만 색칠합니다. 열 경계를 끌면 너비가, 표 아래·오른쪽 ＋ 로 행·열이 늘어납니다. 제목 행·제목 열은 ⠿ 메뉴에서 켜고 끕니다.
엑셀·구글 시트에서 복사해 붙이면 표로 들어오고, 마크다운 표(| a | b |)도 표가 됩니다. 휴대폰처럼 좁은 화면에서는 표가 줄어들지 않고 좌우로 밀어서 봅니다.

열 배치 방식
기본은 표 방식입니다. 아임웹이 display:flex 를 지워서 열이 세로로 쌓이기 때문입니다. 대신 표는 휴대폰에서도 가로를 유지하니, 열이 3개면 좁아집니다.

열 너비·간격
열과 열 사이 경계를 끌면 너비 비율이 바뀝니다. ⠿ → 열 간격 으로 사이 여백(12·24·40px)을, 너비 균등으로 로 비율을 되돌립니다.

열 나누기
/2열 · /3열 로 좌우 배치를 만듭니다. 콜아웃·토글 안에서도 됩니다. 좁은 화면에서는 자동으로 세로로 쌓입니다. 열 개수는 ⠿ 메뉴에서 바꿀 수 있고, 줄이면 남는 내용이 마지막 열로 합쳐집니다.

콜아웃 · 토글 안에 블록 넣기
상자 안에서 엔터로 줄을 늘리고 / 로 제목·목록·버튼·구분선·이미지를 넣을 수 있습니다. 상자 안에 상자는 넣을 수 없습니다.

토글 제목 크기
/토글 제목 2 처럼 넣거나, 만든 토글의 ⠿ → 제목 크기에서 기본·H2·H3·H4 를 고릅니다. 제목 블록 맨 앞에 >  를 쳐도 같은 크기의 토글이 됩니다(노션과 같음). 발행본에서도 진짜 제목(H 태그)으로 들어가 검색에 잡힙니다.

콜아웃 · 토글
안에서는 엔터가 줄바꿈입니다. 빈 줄에서 한 번 더 엔터를 치면 블록을 빠져나옵니다. 콜아웃 이모지는 클릭해서 바꾸거나 없앨 수 있습니다.
